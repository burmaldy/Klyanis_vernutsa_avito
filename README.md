# Авито.Миры — интерактивный прототип

Основной файл: **index.html**. Это продолжение загруженной версии v3 со встроенными изображениями, без сборки и серверных зависимостей.

## Запуск

Из каталога репозитория выполните:

```sh
python3 -m http.server 8000
```

Откройте в браузере локальный сервер на порту 8000. Для предсказуемого сохранения избранного используйте один и тот же адрес и порт.

## Избранное

- Сердце в шапке открывает страницу избранного со счётчиком.
- Сердце на карточке и кнопка в объявлении добавляют или удаляют один и тот же товар.
- На странице показаны только сохранённые объявления, без демонстрационного наполнения.
- Выбор сохраняется в localStorage этого браузера и синхронизируется между вкладками одного адреса. Серверной учётной записи и синхронизации между устройствами нет.
- При пустом списке отображается предложение найти товары.
- Если хранилище браузера недоступно, выбор работает в текущей сессии с уведомлением.

Сохранены сценарии v3: каталог → объявление → сообщество → дом, комнаты покупок и желаний, гостевая стена, взаимодействия с предметами и игровые механики. Нереализованные разделы исходной версии остаются демонстрационными.

## Проверка

Требуются Python, пакет `playwright` и Chromium в `/usr/bin/chromium`:

```sh
python3 tests/favorites_smoke.py
```

Проверка запускает собственный локальный сервер: добавление и удаление из разных экранов, перезагрузка, пустое состояние, повреждённые данные, мобильная ширина и основные маршруты без ошибок JavaScript.

## Обновление оформления

Главная сверена с присланным HTML-образцом: категории показываются только на главной, добавлена кнопка «Найти». Сообщества, дом и избранное доступны в компактной навигации. Поиск работает по всем товарам.

Фотографии товаров созданы для демонстрации: на изображениях нет цен, названий и интерфейсных плашек. Изображения встроены в HTML, загрузка внешних сайтов не требуется. Интерфейсные цены и кнопки избранного отображаются отдельно. Дом обновлён: реалистичная визуализация интерьера, отмеченные товары связаны со своими объявлениями. Под интерьером доступны карточки товаров и избранное. Изображение интерьера демонстрационное; это не 3D-редактор и не реальное фото квартиры. В двух вкладках используется одна визуализация размещения, состав отмеченных товаров различается.

Проверки также контролируют видимость категорий, поиск наушников, размеры изображений и отсутствие горизонтальной прокрутки на мобильном.

## Файл для просмотра

Откройте `index.html` из ветки изменений. В Pull Request основной файл отображается во вкладке **Files changed → index.html**. Для большого HTML GitHub может предложить загрузить diff; сам файл доступен в обычном просмотре ветки.
