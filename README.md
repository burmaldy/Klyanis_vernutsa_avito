# Авито.Миры V9

Готовый автономный файл: **Avito_Miry_v9.html**. `index.html` содержит ту же версию для стандартного просмотра проекта. V9 продолжает существующую V8; исходный архив V8 сохранён в `downloads/Avito_Miry_v8.zip`.

Скачать V9: `downloads/Avito_Miry_v9.zip`. В архиве только `Avito_Miry_v9.html`; CSS, JavaScript и изображения встроены. После распаковки откройте HTML браузером. Сборка, регистрация, API Авито и внешние ресурсы не нужны.

## Что изменено

- Понятный кошелёк «Авикоины» с отдельным демонстрационным рублёвым эквивалентом, историей и защитой от отрицательного баланса. Дневная награда ограничена календарным днём по Москве и сохраняется после перезагрузки.
- У объявлений 4 рекомендации сообществ разных форматов с учётом категории и типа товара. Сохранены каталог, избранное, поиск и публикации V8.
- Вкладки сообществ: «Мои», «Рекомендованные», «Все». В подписках показываются только выбранные группы. Есть обложки, тематика, форматы и демонстрационные счётчики.
- Фотопосты, интервью с вымышленными экспертами, оригинальные мемы, советы, вопросы, подборки и мероприятия. Фильтры работают внутри выбранной группы.
- Чаты сообществ и отдельные чаты мероприятий, отправка и сохранение сообщений, вложенные товары, отмеченные демонстрационные ответы, воспроизводимый/приостанавливаемый демо-макет видеокружочка.
- Четыре демонстрационных мероприятия ноября 2026 с полными данными, участием и разделом «Мои мероприятия». Это не настоящие события Авито.
- Комнаты и внутренние зоны представлены изменяемыми 2.5D-сценами с отдельными реалистичными изображениями вещей. Добавление, выбор, перемещение между фиксированными позициями и удаление меняют сцену и список. Шкаф, полка и гараж имеют состояния пустой/заполненной зоны.
- Независимые профили «Вы» и «Анна»: свои вещи, приватность, стены и игровые кошельки. Закрытая комната недоступна гостю и по прямой ссылке во внутреннюю зону. Владелец может поделиться открытой комнатой через публикацию.
- Демо-покупка переносит товар из желаний в покупки без реальной сделки. Игровые действия, охрана и добровольные виртуальные рейды не затрагивают настоящие вещи или деньги.
- Закрытые объявления предлагают демонстрационные альтернативы с приоритетом типа, характеристик, цены и категории. Отсутствие точного аналога обозначено явно.
- Fallback для отсутствующего `crypto.randomUUID`, безопасное отображение пользовательского текста, закрытие окон по Escape, сохранения через localStorage, адаптивность.

## Проверки

Требуются Python, пакет `playwright` и установленный Chromium в `/usr/bin/chromium`:

```sh
python3 tests/v9_journeys.py
python3 tests/v9_ux.py
```

Оба скрипта сами поднимают временный локальный HTTP-сервер только для автоматизации. Это не зависимость распространяемого HTML.

Десять обязательных сценариев и отдельная попытка `file://` записаны в `tests/v9_journeys_results.json`. UX-проверки — в `tests/v9_ux_results.json`. Читаемый отчёт: **V9_TEST_REPORT.md**. Старые `favorites_smoke.py` и `wishlist_smoke.py` описывают интерфейс V8; для текущей версии используются проверки V9 выше.

## Ограничения

- Управляемый Chromium этой среды запрещает `file://` (`ERR_BLOCKED_BY_ADMINISTRATOR`). Реальное открытие двойным щелчком здесь не удалось проверить. Функциональные сценарии проверены браузером через HTTP; внешних сетевых запросов приложение при проверке не делало.
- Сцены — 2.5D-композиции с фиксированными позициями, не полноценный 3D-редактор. Предметы визуально меняются, свободного drag-and-drop нет.
- Видеокружочки — явно обозначенный интерактивный демо-макет, не записанное видео. Звук колонки заменён анимацией, как разрешено заданием.
- Чаты, ответы, пользователи, фотографии экспертов, события, денежные эквиваленты и покупки демонстрационные. Нет сервера, настоящих платежей и вывода средств.
- Сохранения привязаны к браузеру и доступному origin. При открытии другого файла, смене браузера или адреса доступность прежнего localStorage определяется браузером. Импорт V8 проверен в пределах одного origin, без удаления старых ключей.
- Административное переключение профилей — демонстрация ролей, не настоящая авторизация. Для закрытой комнаты интерфейс скрывает все внутренние данные; серверных прав доступа в локальном прототипе нет.
